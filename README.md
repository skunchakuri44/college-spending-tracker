# College Spending Tracker

## Project Goal
I want to create a Java program that helps college students keep track of their spending and manage their monthly budget.

## MVP Features
- Let users enter their monthly budget.
- Let users enter expenses and choose categories.
- Calculate total spending and show how much money is left.

## Future Features
- Save expenses for later.
- Show spending totals for each category.
- Let users edit or delete expenses.

## Tech Stack
I'll be using Java to build this program and VS Code to write and run my code. I'll use Scanner for user input and ArrayList to store expenses.

## Project Status
I'm currently setting up the project and planning out the features.
